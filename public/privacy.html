Privacy Policy — IT Cafeteria Studio

Last updated: October 26, 2026

1. Overview

IT Cafeteria Studio is a private, password-protected dashboard used only by the owner of the YouTube channel and TikTok account @itcafeteria. This policy explains what data the service touches.

2. Data we access

  • YouTube (with the owner's authorization): channel statistics (views, watch time, subscribers, traffic sources) via the YouTube Data API and YouTube Analytics API.
  • TikTok (with the owner's authorization): the owner's own profile, follower counts, and video statistics via the TikTok Display API.
  • AI prompts: text the owner types to generate scripts, ideas, and thumbnails is sent to Google's Gemini API for processing.

3. What we never do

  • We never access data of other users' accounts.
  • We never publish, upload, or modify content on YouTube or TikTok.
  • We never sell or share data with third parties.

4. Storage and security

OAuth access tokens are stored encrypted (AES-256-GCM) in HttpOnly, SameSite cookies on the owner's own browser and are never written to disk or logs. Analytics responses are cached in server memory for a few minutes to reduce API calls and are then discarded.

5. Retention

Analytics data is fetched on demand and is not retained long-term. Disconnecting a platform from the dashboard immediately deletes its stored token.

6. Contact

Privacy questions can be raised through the IT Cafeteria YouTube channel.
